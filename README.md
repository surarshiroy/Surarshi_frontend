🚀 Netflix Clone - High Fidelity UI
Project Overview
As a beginner in web development, I’ve spent the last few days diving deep into HTML and CSS to recreate the Netflix landing page from scratch. My main focus was on the "pure" fundamentals—no frameworks, just clean code and CSS math.

The Challenge: Creating the iconic cinematic curve and purple glow transition. This project taught me so much about gradients, positioning, and responsive design. I'm excited to take these skills into my next challenge: JavaScript! 💻✨

🛠️ Technical Highlights
Cinematic Header: Built with a dark background overlay and high-fidelity styling.

The Curve: Used advanced CSS gradients to replicate the red-purple glowing transition.

Trending Slider: Features large, outlined ranking numbers for trending titles.

Interactive FAQ: A clean section with plus icons for a professional look.

Styled Footer: Centered email and "Get Started" inputs for a balanced design.

💡 What I Learned
How to handle complex CSS Positioning without relying on frameworks.

Designing for Mobile Stack and ensuring hover effects feel smooth on desktop.

Managing High-Fidelity UI details to match a world-class brand.
